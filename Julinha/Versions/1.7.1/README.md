# Julinha Chan — versão anterior 1.7.1

Snapshot histórico da versão anterior à migração para 1.8.

Esta cópia preserva o código da versão 1.7.1, mas não inclui `.env`, tokens nem bancos de dados. O arquivo `server_settings.json.example` foi substituído por um modelo vazio porque o original continha IDs e perfis predefinidos. A configuração de notificação de inicialização foi alterada para aceitar apenas um ID fornecido localmente pela variável `STARTUP_NOTIFY_USER_ID`.

Esta pasta é apenas um arquivo histórico; a versão ativa fica em `Julinha/`.
